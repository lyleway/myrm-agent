# lib/intent-dispatcher/

Slash/深链意图分发 schema、解析与执行（schema 纯函数；执行经动态 import 接应用 store）。

| 文件        | 职责                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schema.ts` | 意图 payload Zod schema 与 `parseIntentUrl`（oauth 为 `exchange`+`state`；`app` 为 `myrmagent://app/<产物 ID>`，ID 限定字母、数字、`-`、`_`，至多 64 位，与桌面壳窗口标签的字符集一致）；`redactIntentUrl` 日志脱敏                                                                                                                                                                                                                                                                                                                                                                                                            |
| `index.ts`  | 解析与路由门面（`dispatch` 返回成功态，支持接收页面层已解析 intent，避免重复解析）；OAuth 回调须携带本机发起时生成的 `state`（一次性、5 分钟有效，错误/过期/重放即拒绝）；进行中会话的知情确认由设置页在发起登录前完成，回跳时直接切换：消耗待决授权后经控制平面 `exchange`（带 PKCE verifier）兑换、验沙箱列表，再 `switchRemoteFollow(true)` 真正切换连接，成功后才落 token 并建 Cloud 档案，落地设置页系统页签；日志统一经 `redactIntentUrl` 脱敏；`app` 意图在桌面端打开该应用自己的窗口（窗口标题由应用页读到名字后设置），不把主窗口拉到前台；窗口打不开或非桌面端时回到主窗口的 `/apps/<id>`；toast 文案经 `IntentMessages` 由调用方按当前语言注入（`intentDispatcher` 命名空间） |
