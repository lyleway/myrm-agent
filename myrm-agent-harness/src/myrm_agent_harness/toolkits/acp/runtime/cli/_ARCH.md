# cli/

## Overview
CLI runtime backend — spawns one external CLI agent process per turn (Claude Code, or any CLI that prints NDJSON events or plain text) and streams its output as `RuntimeEvent`s. Conversations continue through the CLI's own session id: it is stored the moment the CLI announces it (Claude `system/init`) and replayed with the CLI's resume syntax. The agents with a protocol of their own are not run here: Gemini and Qwen speak ACP (`../acp/`), Codex runs its app server (`../codex/`).

## File & Submodule Index

| File | Role | Description | I/O/P |
|------|------|-------------|-------|
| __init__.py | Package | Facade: lazy `CliRuntime`. The other modules are imported by their own path. | ✅ |
| claude.py | Core | What running Claude Code takes beyond a plain command (module functions; `is_claude` tells it by the program name): resume syntax (Claude `--resume <id>`), native turn limit (Claude `--max-turns`), partial-message streaming, default environment (`env_defaults`: Claude `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`, so a headless turn leaves no background task that keeps `claude -p` alive); permission prompts to the host (`asks_host`, `with_permission_bridge`: Claude `--permission-prompt-tool` + `--mcp-config`; the bridge's `--mcp-config` entry carries a per-server `timeout` of a day, because Claude refuses a prompt by itself after 60 seconds, and after 300 seconds without a reply, otherwise; the `MCP_TOOL_TIMEOUT` environment variable lifts only the 60 seconds); the host's MCP servers (`mcp_config_file`, `with_mcp_servers`: a `--mcp-config` file made readable by this user only and deleted when the turn ends, so a credential never reaches argv; `--allowedTools mcp__<server>` for a server declared `read_only`, so its tools run without the permission prompt); session-id shape check (`is_session_id`); attached images (`with_image_blocks`: Claude adds `--input-format stream-json` and writes the prompt plus one base64 block per image as a single stream-json user message on stdin, only on a turn that has images — the CLI's own `@<path>` file mention silently drops every image above 256 KiB). Any other CLI is spawned as configured. | ✅ |
| failure.py | Core | `classify_failure`: the `AcpError` of a finished attempt from the CLI's own words (Claude `result` line plus the `assistant` line's `authentication_failed` category: auth (HTTP 401, or no API call because nobody is logged in; a 403 is not a login problem) / rate limit; else exit code → crash carrying the CLI's last `error` notice or its stderr tail, condensed); reaching the turn limit is no failure (the turn ends DONE with its reason); a process this runtime stopped is a cancellation, never a crash — except one it stopped for retrying a 401 (`auth_rejection`), which is the auth failure the CLI was about to report. | ✅ |
| parser.py | Internal | Event builders shared by the output formats (tool call / result with one-line summary and bounded output, usage, thinking) and `error_text`, the raw text of an `error` line whatever shape it has. | ✅ |
| permission_bridge.py | Core | `PermissionBridge`: the loopback MCP endpoint Claude Code asks its permission prompts through (`--permission-prompt-tool`). One per turn: a real uvicorn on 127.0.0.1 with a port chosen by the OS, a random bearer token checked on every request, a `0600` `--mcp-config` file removed when the turn ends, and one tool, `approve(tool_name, input, tool_use_id)`, whose answer is the JSON Claude acts on (`allow` with the input, or `deny` with the reason the model is told). Each call becomes a `PermissionRequest` for the turn's `TurnPermissions` — the tool kind and one-line title are derived from Claude's tool name and input, the paths from its path-like fields. Leaving the turn cancels the calls still waiting and stops the server within a second. | ✅ |
| runtime.py | Core | `CliRuntime`: launches a turn, resumes the announced session (only from the directory that created it), retries a rejected resume once as a fresh session in the same turn, persists the announced id at once, gives the host's MCP servers to Claude Code only (any other CLI runs without them and the turn says so with `mcp_not_attached`), applies a stop that lands before the process exists, says `working` (elapsed time) every 15 s of CLI silence so a host's idle watchdog does not mistake a long quiet turn for a hung one, stops a turn whose CLI keeps retrying a request the API answers 401 for (the CLI would take minutes to fail with the same words), reports a missing program once as `BACKEND_NOT_FOUND`, and ends the turn with DONE (`stop_reason` `end_turn`, or `max_turn_requests` when Claude stopped at its own turn limit) or the one classified ERROR. A `safe` turn of a CLI that can ask (`asks_host`) with a broker runs behind a `PermissionBridge` and starts the CLI with the permission-prompt flags; an `allow_all` turn, a turn without a broker and a CLI that cannot ask start it exactly as before, so the CLI's own policy (Claude's headless default refuses what needs asking) applies; a bridge that cannot start ends the turn with an ERROR instead of running the CLI unguarded. The process is owned by `../process.py`, the session records by `../session_book.py`. | ✅ |
| turn_parser.py | Core | `TurnParser`: stateful per-turn NDJSON parser (Claude content blocks / `stream_event` text deltas deduplicated against the full message, one generic event per line, plain text) exposing the announced session id, the CLI's own `result` verdict and the last top-level `error` text as `notice` (a CLI may print one per request retry, so it is not a failure by itself); it counts consecutive 401 retries (Claude `system/api_retry`) and reports `auth_rejection` after 3. The text that follows a tool call starts a new paragraph (the agent streams the messages around a call with nothing between them), and `CliResult.hit_turn_limit` says Claude stopped at the limit it was given. | ✅ |
