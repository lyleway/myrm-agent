# processing/

## Overview
Post-fetch content processing: HTML to Markdown, pruning, sanitization, URL normalization and rewriting, full-content delivery (one shared budget, complete text saved), anti-bot, binary routing.

## File Index

| File | Role | Description | I/O/P |
|------|------|-------------|-------|
| __init__.py | Package | Re-exports ContentPipeline | ✅ |
| pipeline.py | Core | ContentPipeline — HTML/JSON/XML to Markdown; `run_on_conversion_thread` runs CPU-bound HTML conversions on the dedicated conversion thread while preserving contextvars; applies `static_page_gate` for L1 2xx long static pages pruned to empty; a text response (`PayloadKind.TEXT`) becomes a Document verbatim. A Document built from a source the fetcher cut at its size ceiling (`FetchResult.source_truncated`) carries `SOURCE_TRUNCATED_KEY` in its metadata, whichever path `process` took (the binary router flags the files it cuts itself); the pipeline itself never shortens a Document, so what the page holds reaches the caller | ✅ |
| static_page_gate.py | Util | `should_fallback_to_raw_markdown`: accepts raw Markdown fallback only when L1 HTTP + 2xx + visible Markdown chars (excluding images, link URLs, punctuation) >= 3,000 and >= 4% of HTML length; images and links are stripped with the linear scan of `utils.markdown_links`, so a page of unclosed `[` costs time in proportion to its length | ✅ |
| content_sanitize.py | Util | Strip base64 blobs from markdown | ✅ |
| content_pruning.py | Util | Boilerplate/noise pruning; strips language-switcher lists and non-visible DOM elements (`strip_non_visible_elements`) before scoring, delegates bottom-up subtree metrics to `pruning_metrics.py`, and prunes with an explicit stack; a page nested beyond the scoring limit skips the scoring passes and keeps the structural cleanup. An element is dropped as hidden when its class is `hidden`, starts with `hidden-` or is hidden by breakpoint (`sm`, `md`, `lg`, `xl`, `2xl` followed by `:hidden`, a copy shown on small screens only); a state variant such as `dark:hidden` or `group-hover:hidden` hides content only for a theme or pointer state, so the element stays (a dual-theme code block keeps one copy) | ✅ |
| pruning_metrics.py | Util | Iterative DOM measurement (`dom_path_units`, `compute_subtree_metrics`) matching BeautifulSoup's minimal HTML formatter without temporary Tag allocation | ✅ |
| language_switcher.py | Util | `strip_language_switchers`: removes `<ul>`/`<ol>` lists with >= 8 `<li>` items where >= 80% contain `a[hreflang]`, unless the list exceeds 50% of page text (translation index guard) | ✅ |
| html_to_markdown.py | Util | HTML to Markdown conversion; strips non-visible DOM elements (`strip_non_visible_elements`) before conversion; a table lists the rows of its nested tables itself via precomputed `tables_with_rows`, so nesting depth never multiplies the output | ✅ |
| html_to_markdown_helpers.py | Util | `ConvertOptions`, `BLOCK_TAGS`, `parse_ol_start`, `resolve_url`, bottom-up `tables_with_rows`, and iterative non-visible DOM stripping (`is_hidden_dom_element`, `strip_non_visible_elements` for `template`/`iframe`/`object`/`embed`/`noscript`, `hidden`, `aria-hidden="true"`, `input[type=hidden]`, and inline `display:none`/`visibility:hidden\|collapse`) for `HTML2Markdown` and `ContentPruningFilter` | ✅ |
| markdown_table.py | Util | Markdown table layout of converted table rows: the header and delimiter lines span the widest row and body rows keep their own cells, so one wide row among many short ones never multiplies the output (blank header when the table has none) | ✅ |
| markdown_generator.py | Util | Markdown document generation; fails closed (logs WARNING with traceback and returns empty string instead of error text) when conversion or filtering raises | ✅ |
| url_normalizer.py | Util | `normalize_url`: canonical URL used as the fetch cache key — known tracking parameters (`utm_*`, `fbclid`, ...) dropped but not generic names such as `ref` or `source`, which can select content; scheme and host lowercased, default port dropped, a plain anchor dropped while a hash route (`#/...`, `#!/...`) stays, repeated slashes collapsed, query sorted | ✅ |
| github_blob_url.py | Util | `github_blob_to_raw`: the `/raw/` URL of a github.com blob page (`/<owner>/<repo>/blob/<ref>/<path>`, query and fragment dropped), any other URL unchanged — another host, `www.`, a port or credentials, a path with an empty segment. The blob page wraps the file in a large HTML page that the HTTP tier cuts at its body ceiling; `/raw/` is the file, and GitHub resolves a branch name with slashes itself, so nothing here guesses where the ref ends. The engine applies it before the cache key (a blob link and a raw link share one entry); the redirect to `raw.githubusercontent.com` is judged by the fetch like any hop, so a blocklisted `raw.githubusercontent.com` still stops it | ✅ |
| full_content_delivery.py | Core | Delivery plan for full-content reads: one shared character budget split max-min fairly across pages, a truncation window per cut page, the exact saved-file line range of every omitted section, newline-normalized and soft-wrapped saved text, failed-URL listing with per-URL trusted failure classification labels (`blocked` / `not_found` / `needs_javascript` / `error_page`) and the trusted guidance of each classified kind outside the untrusted boundary (stop retrying a blocked page, find another source for an HTTP 404/410 dead link, ask before opening a browser for a page that needs JavaScript), taken from one table that a delivery with pages (`failure_notice`) and an all-failed result both use, so a kind cannot be answered in one and left silent in the other; pages are labelled with the numbers the caller gives (`indices`: the run's source numbers, so a label is the index of the page's card), from 1 when none; `source_notice` names, by those numbers only (so it may sit outside the untrusted boundary), the pages whose source was cut, by the fetcher at its size ceiling or by the binary router at its parsed-text cap | ✅ |
| spill.py | Util | Saves the complete text through the injected evicted-content callbacks, builds the read guide and announces the saved file to the GUI; `stored_copy_capacity()` is how much text that copy keeps (`core.evicted_limits.MAX_STORED_CHARS`), or `None` when no store is registered, which is what a caller with a store asks the crawl to parse up to | ✅ |
| html_scan.py | Util | Linear-time scans of raw HTML text (title, body, script/style blocks) for pages that may be hostile | ✅ |
| antibot_detector.py | Util | `classify_block(status_code, html, headers)` and `is_blocked(status_code, html)`: classifies crawl failures into three `BlockKind` values (`"blocked"`, `"needs_javascript"`, `"error_page"`). Tier 1 WAF markers, `cf-mitigated: challenge` / `x-amzn-waf-action: challenge` headers, HTTP 403/429, and HTTP 202 script-only shells classify as `"blocked"`; Tier 3 empty JS shells on 200 classify as `"needs_javascript"`; plain HTTP 5xx outages without WAF markers and generic non-access-denied error pages classify as `"error_page"` (so `is_blocked()` still rejects error HTML as content without triggering false WAF stop guidance). Other 4xx (404, 410, ...) stay with content rules, and JSON/XML bodies are exempt | ✅ |
| charset_detector.py | Util | Tiered charset detection of a fetched body: header charset, `<meta>` charset, strict UTF-8, CJK trial decodes, then a replacement decode. `partial` marks a body cut at an arbitrary byte: its last half character is dropped, so the cut cannot fail the strict decodes or let a CJK trial decode read the page as mojibake. Needs only the standard library | ✅ |
| binary_router.py | Util | Binary content type routing (Content-Type, Content-Disposition, then `utils.content_sniff.magic_extension`); a body over `MAX_BINARY_SIZE` (20 MB, also the L1 transfer bound) is dropped, and a payload no parser accepts is rejected, never decoded as text; a body that is a ZIP container (judged by its content, whatever the headers say) is measured by `file_parsers.archive_budget.check_zip_budget` before any parser opens it, because the 20 MB cap counts compressed bytes only, and a container over the unpacking budget or member limit is dropped like an oversized body; the extension detection and that measurement run on worker threads; a parsed text over the caller's `max_chars` (`MAX_PARSED_CHARS`, 100,000 characters, when it sets none) is cut and its Document carries `SOURCE_TRUNCATED_KEY`, so the full-content tool names it in the size-limit notice | ✅ |
